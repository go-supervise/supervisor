# supervisor (`svd`)

`svd` is a cross-platform service supervisor (Linux, macOS, Windows).

**Status: design.** Nothing here runs yet. The authoritative design is
[docs/design/SUPERVISOR.md](docs/design/SUPERVISOR.md) (draft 7); the
bibliographies and reviews it rests on sit beside it in `docs/design/`.

Phase P0 is `Compile`: parsing and validating service descriptions and
composing them across authorities (recipe, site, user). It lands in a
separate pull request.
